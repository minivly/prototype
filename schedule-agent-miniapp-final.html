  • 결정사항은 "완료" 상태가 없습니다 — 회의에서 무엇을 정해야 하는지를 적어둔 것이지 체크리스트가 아닙니다. 그래서 체크박스나 완료 표시를 붙이지 않고, 왼쪽 세로선으로 구분만 했습니다.
  • 데이터가 없는 항목은 카드째 숨깁니다 — 첨부 파일이 없으면 "없음"이라고 쓰지 않고 카드 자체를 그리지 않습니다. 빈 카드가 늘어날수록 스크롤만 길어집니다.
  • 참석자 이름을 누르면 인물 정보 화면으로 이동합니다 (§03).
  • 일시는 오늘 16:00~17:00처럼 상대 표현을 쓰고, 오늘이 아니면 8월 13일(목) 16:00~17:00으로 표기합니다.

중요 일정 모아보기
메인 화면에 섹션으로 넣지 않았습니다 — 이전 버전에서 메인에 "★ 중요 일정" 섹션을 두었을 때, 오늘 일정만 보는 화면에 다른 날짜가 섞여 구조가 무너졌습니다. 중요 일정은 날짜를 넘나드는 목록이라 성격이 다릅니다. 그래서 메인은 오늘에만 집중시키고, 중요 일정은 상단 버튼으로 진입하는 별도 화면으로 분리했습니다.
  • 별 위치 — 다음 일정 카드와 상세 화면은 제목 오른쪽, 예정 카드는 오른쪽 끝 세로 가운데입니다. 어디서든 한 번에 켜고 끌 수 있습니다.
  • 지나간 일정 목록에는 빈 별(☆)을 그리지 않습니다 — 이미 끝난 일정에 새로 표시할 일은 드문데 별이 줄마다 늘어서면 목록이 지저분해집니다. 이미 표시된 건만 ★로 보여주고, 새로 표시하려면 상세로 들어가서 누릅니다.
  • 상단 버튼에 건수를 함께 표기합니다 — 아이콘만 있으면 눌러보기 전까지 안에 뭐가 있는지 알 수 없습니다. ★ 3처럼 숫자가 붙으면 열지 않고도 파악됩니다. 0건이면 버튼을 흐리게 두되 숨기지는 않습니다(기능 발견을 위해).
  • 모아보기는 날짜별 그룹입니다 — 오늘 → 다가오는 날짜 → 지난 일정 순입니다. 지난 일정을 지우지 않는 이유는, 끝난 뒤 결정사항을 되짚어보려고 표시해두는 경우가 있기 때문입니다.
  • 취소·삭제된 일정은 목록에서 자동으로 빠집니다 — 별도 정리 동작 없이 사라지고, 상단 건수도 함께 줄어듭니다.
빈 상태 — 표시한 일정이 하나도 없으면 목록 대신 "중요 표시한 일정이 없습니다 / 일정의 ☆를 눌러 추가하세요"를 보여줍니다. 이 화면은 사용자가 직접 채워야만 내용이 생기는 화면이라, 처음 들어왔을 때 무엇을 해야 하는지 알려주지 않으면 빈 화면으로 끝납니다.
확인 필요 — 비서실이 이 표시를 볼 수 있어야 할까요? 회장님이 어떤 일정에 별을 달았는지 비서실 Admin에서 보이게 하면, "회장님이 신경 쓰는 일정"을 미리 알고 자료를 더 챙기는 데 쓸 수 있습니다. 반대로 회장님 개인의 메모 성격이라 남이 보지 않는 편이 자연스럽다는 판단도 가능합니다. 데이터 설계(사용자별 플래그를 Admin에 노출할지)와 직결되므로 개발 착수 전에 정해야 합니다. 현재 시안은 회장님 전용(비서실 미노출)을 전제로 그렸습니다.
05 · Changes

이전 버전에서 뺀 것

최종 3화면으로 정리하면서 이전 시안에 있던 아래 요소들이 빠졌습니다. 나중에 "왜 없어졌지"를 다시 논의하지 않도록 이유를 남겨둡니다.

★ 중요 일정 섹션 (메인 내 섹션) → 별도 화면으로 대체 — 메인 화면 안에 있던 섹션은 제거했습니다. 등록 양식에서 "중요일정 여부" 체크박스가 없어져 데이터 근거가 사라졌고, 오늘만 보는 화면에 다른 날짜가 섞이는 구조 문제도 있었습니다. 대신 회장님이 직접 누르는 즐겨찾기로 성격을 바꿔 §04의 별도 화면으로 되살렸습니다 — 비서실 등록값이 아니라 사용자 표시라는 점이 다릅니다.
브리핑 보기 버튼 — 상세보기와 나란히 있던 두 번째 버튼으로, 비서실이 따로 등록한 서술형 브리핑으로 가는 통로였습니다. 최종안에서는 상세보기 하나로 단일화했습니다. 버튼이 두 개면 무엇이 다른지 회장님이 매번 판단해야 하고, 비서실 브리핑이 등록된 일정에만 나타나 있을 때와 없을 때의 화면이 달라지는 문제도 있었습니다.
보안 등급 표시 — 일반/보안 등급에 따라 AI 브리핑 생성을 건너뛰던 처리입니다. 등급 체계 자체가 확정되지 않아 이번 범위에서 제외했습니다.
폴드 펼침(와이드) 마스터-디테일 — 갤럭시 폴드를 펼쳤을 때 좌측 목록·우측 상세로 나누던 레이아웃입니다. 최종 3화면은 접힌 상태(단일 컬럼) 기준으로만 확정했습니다. 펼침 대응이 필요하면 별도로 정의해야 합니다.
사내 인력 인물 화면 — 외부 인력과 다른 구성(약력·학력 중심)이 필요한 별도 화면입니다. 최종 3화면에 포함되지 않아 보류합니다.
