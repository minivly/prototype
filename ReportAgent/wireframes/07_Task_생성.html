새 Task 생성

생성 즉시 Task 목록에 반영되며, 이후 자료 추가·회의록 등록 등 사후관리도 이 Task를 기준으로 진행됩니다.

일정 · 연결 (선택)
생성 시 자동 처리 안내 Task가 생성되면 담당 조직에 알림이 전달되고, 희망 일정을 입력한 경우 일정 에이전트로 조율 요청이 자동 전달됩니다. 보고회의 에이전트는 이후 업로드되는 자료를 점검 프레임 기준으로 자동 검수합니다.
생성 후 Task 관리 목록에서 바로 확인할 수 있습니다.
