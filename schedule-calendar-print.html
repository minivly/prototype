일정 관리 — 달력 프린트 화면

"일정 화면 프린트" 버튼을 눌렀을 때 나오는 출력물입니다. 화면용 달력은 셀 높이가 고정이라 일정이 3건을 넘으면 +N개 더보기로 감추고 제목도 잘리는데, 인쇄물은 손에 들고 보는 것이라 감출 곳이 없습니다. 모든 일정을 자르지 않고 전부 노출하는 것이 이 화면의 유일한 목적입니다.

01 · Print Rules

화면과 다르게 동작하는 5가지

아래는 프린트에서만 적용되는 규칙입니다. 화면용 달력의 동작은 그대로 두고, 인쇄 시점에만 무효화합니다.

RULE 01
셀 높이 고정 해제
행 높이를 내용에 맞춰 자동으로 늘립니다. 일정이 몰린 주는 행이 두꺼워지고, 한 건도 없는 주는 날짜 숫자만 들어갈 만큼 얇아집니다. 모든 행을 같은 높이로 맞추지 않습니다.
RULE 02
잘림·말줄임 없음
일정명이 길면 셀 안에서 줄바꿈합니다. text-overflow: ellipsis와 nowrap을 해제하고, 시각은 왼쪽에 고정한 채 제목만 흐릅니다. 한글은 word-break: keep-all로 단어 중간이 끊기지 않게 합니다.
RULE 03
"+N개 더보기" 제거
화면에서 3건까지만 보여주고 나머지를 접던 처리를 인쇄에서는 해제하고 전부 펼칩니다. 8월 10일의 +1개 더보기에 숨어 있던 네 번째 일정도 그대로 나옵니다.
RULE 04
지난 일정도 동일하게
화면에서 흐리게(회색) 또는 취소선으로 처리하던 지난 일정을 인쇄에서는 다른 일정과 똑같은 농도로 출력합니다. 종이는 기록용이라 지난 일정이 더 중요할 수 있고, 옅은 회색은 인쇄 품질에 따라 아예 안 찍힙니다.
RULE 05
취소된 일정은 제외
취소된 일정은 인쇄물에서 아예 빼고 출력합니다. 기호를 쓰지 않기로 한 이상 취소 건을 남겨두면 살아 있는 일정과 구분되지 않아, 종이만 보는 사람이 그대로 진행되는 일정으로 읽게 됩니다. RULE 04와 구분됩니다 — 지나간 일정은 남기고, 취소된 일정만 뺍니다.
흑백 인쇄 기준 · 기호는 쓰지 않습니다 — 화면의 색 점(● 검정 / ● 주황)과 붉은 텍스트는 흑백 출력에서 회색조로 뭉개져 구분되지 않고, 기호(⚠ · × 등)는 인쇄물에 툴팁이 없어 받는 사람이 해석할 수 없습니다. 그래서 인쇄물은 시각과 일정명만 남깁니다 — 모든 일정을 같은 격으로 나열하고, 색·기호로 상태를 구분하지 않습니다. 색상 프린터로 뽑아도 정보가 더 늘지 않습니다.

03 · Weekly

주간 프린트 — 시간 그리드

주간은 월간과 문제가 다릅니다. 월간은 "며칠에 무엇이 있는지"를 보지만, 주간은 일정의 길이와 간격을 보려고 씁니다. 그래서 시간 그리드를 없애면 주간 뷰를 인쇄할 이유 자체가 사라집니다. 그리드는 유지하되, 짧은 일정의 제목이 잘리지 않도록 아래 3가지를 추가로 적용했습니다.

RULE 06
1시간 칸을 넉넉하게
1시간 = 28mm로 잡았습니다. 30분짜리 일정도 14mm를 확보해 시각·일정명(2줄)·참석자가 모두 칸 안에 들어갑니다. 화면 밀도 그대로 가면 짧은 일정이 곧바로 잘립니다.
RULE 07
칸이 내용만큼 늘어남
일정 박스 높이는 고정이 아니라 최소값입니다(min-height). 제목·참석자가 길면 박스가 아래로 늘어나 글자가 박스 밖으로 나가지 않습니다. 월간의 행 확장과 같은 원리입니다.
RULE 08
시간대로 나눠 여러 장에
칸을 키운 만큼 하루가 한 장에 안 들어갑니다. 시간 그리드는 페이지 경계에서 박스가 잘리므로 브라우저 자동 분할에 맡기지 않고 시간대로 끊어 장을 나눕니다 — 08:00~13:00 / 13:00~18:00. 각 장에 요일 헤더를 반복합니다.

주간에서도 월간과 같은 규칙이 그대로 적용됩니다 — 지나간 일정(8/10 오전 2건)은 흐리게 처리하지 않고 같은 농도로, 취소된 일정(8/11 인사 관련 독대, 8/13 M&A 검토 보고)은 아예 빼고 출력합니다. 화면의 색 점·자물쇠·× 기호도 모두 제거했습니다. 현재 시각을 나타내던 빨간 선은 종이에서 의미가 없어 지웠습니다 — 출력 시각은 상단에 있습니다.
확인 필요 — 같은 시간대에 일정이 겹칠 때 이번 주 데이터에는 시간이 겹치는 일정이 없어 한 칸에 하나씩 들어갔습니다. 실제로 겹치는 경우 화면에서는 칸을 좌우로 나눠 표시하는데, 인쇄에서 폭을 반으로 나누면 제목이 다시 잘립니다(37mm → 18mm). 세 가지 중 하나를 정해야 합니다: ① 화면처럼 좌우 분할(제목 잘림 감수) ② 위아래로 밀어서 순서대로 배치(시간 위치가 실제와 어긋남) ③ 겹치는 날만 해당 칸을 넓히고 다른 요일을 좁힘. 겹침이 얼마나 자주 생기는지에 따라 답이 달라집니다.
04 · Implementation

적용 CSS

화면용 마크업을 그대로 두고 프린트 스타일만 덧씌우는 방식입니다. 달력을 div 그리드가 아니라 table로 만들어 두면 행 높이 자동 확장과 페이지 넘김 처리가 브라우저 기본 동작으로 해결됩니다.

/* 용지 — A4 가로 고정 */
@page { size: A4 landscape; margin: 10mm; }

@media print {
  /* 사이드바·툴바·주간월간 토글 등 화면 전용 UI 제거 */
  .app-sidebar, .app-toolbar, .view-toggle, .btn-group { display: none !important; }

  /* RULE 01 — 셀 높이 고정 해제, 내용만큼 늘어나게 */
  .cal td { height: auto !important; min-height: 0 !important; vertical-align: top; }

  /* RULE 02 — 자르지 않고 줄바꿈 */
  .cal .ev {
    white-space: normal !important;
    overflow: visible !important;
    text-overflow: clip !important;
    word-break: keep-all;          /* 한글 단어 중간 끊김 방지 */
  }

  /* RULE 03 — 접힘 해제 */
  .cal .ev--hidden { display: flex !important; }
  .cal .more-link { display: none !important; }

  /* RULE 04 — 지난 일정도 동일 농도 */
  .cal .is-past, .cal .is-past * {
    opacity: 1 !important;
    color: #000 !important;
    text-decoration: none !important;
    background: transparent !important;
  }

  /* RULE 05 — 취소된 일정은 인쇄에서 제외 */
  .cal .ev--cancelled { display: none !important; }

  /* 페이지 넘김 — 요일 헤더 반복, 주 단위로 쪼개지지 않게 */
  .cal thead { display: table-header-group; }
  .cal tr    { break-inside: avoid; page-break-inside: avoid; }
  .cal .ev   { break-inside: avoid; page-break-inside: avoid; }

  /* 배경·테두리가 인쇄에서 누락되지 않도록 */
  * { -webkit-print-color-adjust: exact; print-color-adjust: exact; }
}
취소 건은 CSS로 감추기보다 서버에서 빼는 편이 안전합니다 — 위 display:none은 마크업을 그대로 두고 시각적으로만 감추는 방식이라, 건수 집계가 어긋나고 취소된 일정 제목이 HTML에는 남습니다. 인쇄용 데이터를 따로 내려주는 구조라면 취소 상태를 쿼리 단계에서 걸러 아예 렌더링하지 않는 쪽을 권합니다. CSS 규칙은 화면 마크업을 그대로 재사용해야 할 때의 차선책입니다.
페이지가 넘어가는 경우 — 일정이 몰린 달은 A4 한 장을 넘길 수 있습니다. display: table-header-group으로 요일 헤더가 2페이지에도 반복되고, break-inside: avoid로 한 주가 중간에 잘리지 않습니다. 한 주가 통째로 한 페이지를 넘길 만큼 일정이 많은 예외 상황에서만 해당 주가 분할됩니다.
건수는 취소 건을 뺀 값으로 다시 계산합니다 — 취소 일정을 감추기만 하면 상단의 "총 48건"과 날짜 옆 10건 배지가 실제 인쇄된 줄 수와 어긋납니다. 두 숫자 모두 취소 건을 제외한 값으로 집계해야 합니다. 그리고 화면에는 있던 일정이 인쇄물에서 사라지면 받는 사람이 누락으로 오해할 수 있어, 용지 상단에 취소 3건 제외를 한 줄 적어 명시했습니다.
